<h1 align="center">HURF · حرف</h1>
<p align="center"><b>Early reading-difference screening in Urdu for Class 1–5 children</b><br>

---

HURF helps a teacher check whether a child may have reading difficulties such as dyslexia.
It takes about **10 minutes**, in **Urdu**, on a basic Android phone, and needs **no internet**.

> HURF only flags risk. It **never diagnoses**. Children marked high risk should be referred to a specialist.

## ⬇️ Download

**[Download HURF-v1.1.0.apk](../../releases/latest)** from the Releases page (5.5 MB),
or take [`HURF-v1.1.0.apk`](HURF-v1.1.0.apk) from this repository.

### Install on Android
1. Download the APK on the phone, or send it over WhatsApp, USB or Google Drive.
2. Tap the file. If Android asks, allow **Install unknown apps** for your browser or file app.
3. Open **HURF حرف** and turn the phone volume up. Hurfi the owl speaks Urdu out of the box,
   offline, with nothing else to install.

Needs Android 5.1 or newer.

## 🎮 What the child does
Seven short games with big buttons, pictures and a friendly owl, Hurfi:

| | Game | Checks |
|---|---|---|
| ب | Hear a letter, tap it | Letter knowledge |
| 👀 | Find the different letter | Visual discrimination |
| 👂 | Which picture starts with this sound? | Sound awareness |
| 📖 | Read the word aloud | Word reading and speed |
| 🧩 | Read made-up words | Decoding |
| 🎨 | Name the colours fast | Rapid naming |
| ✏️ | Copy the word with a finger | Handwriting |

Hurfi speaks every instruction and says "شاباش!" after every answer. The child never sees or hears "wrong".

### 🦉 Practice with Hurfi
After the screening, children can practise letters for 5 minutes a day. Hurfi says a letter and the child
touches it. Look-alike letters (ب پ ت ٹ ث…) are mixed in, a miss is gently shown and repeated, and letters
missed last time come back first.

## 👩‍🏫 What the teacher gets
- 🟢 / 🟡 / 🔴 risk level, adjusted for the child's class
- A score for each skill, with strengths and needs in plain Urdu or English
- A **4-week support plan** for home and school
- A referral note for high-risk children
- **Listen again**: optionally record the child reading each word, then replay it in the report
- Practice tracking for each child: rounds done, last score and letters still hard
- Record Hurfi's lines in your own voice, if you prefer (Settings)
- Progress over time, sharing, and CSV export

## 🔒 Privacy
Everything stays on the phone, including any voice recordings. There is no account, no server and no tracking.
Parent or guardian consent is confirmed before each screening.
